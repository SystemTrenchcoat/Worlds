First things first: You have 4 free skills, called **Origin Skills**. They can be the outer most node of any tree listed below, or any node within [[Adaptation]].

Following this, you should decide if you want to use [[Spellcraft]] or not.

If you use magic, there are 11 abilities (**Spellcraft**, Diligence, Deftness, Prowess, Power, Fortitude, Will, Discern, Convey, Agility, and Recall). Each one may have one dice from the following array: 3d4, 2d6, 2d8, 2d10, 2d12.

If you do not use magic, you have the listed abilities barring spellcraft (Diligence, Deftness, Prowess, Power, Fortitude, Will, Discern, Convey, Agility, and Recall). Each one may have one dice from the following array: 1d4, 2d6, 2d8, 2d10, 2d12, 1d20.

You then get 20 [[Skill Points]] (not to be confused for skill pills) to use as you see fit. Each node has a listed cost. When you select that node, subtract the cost from your total and keep going until you have the skills you want, or run out of points. The GM can choose to change the number of [[Skill Points]] if they so desire.

Remember, if you are going to buy a skill, you need to have whatever prereqs. that it has listed, as well as at least 1 of the skills directly before it. There should be an unbroken line of abilities.

The main skill trees are:

- [[Adaptation]]
- [[Combat]]
- [[Crafting]]
- [[Exploration]]
- [[Social]]
- [[Spellcraft]]
