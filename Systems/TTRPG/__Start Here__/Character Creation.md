First things first: You have 4 free skills, called **Origin Skills**. They can be the outer most node of any tree listed below, or any node within [[Adaptation.canvas]]. If a node has a purple border, it costs 2 **Origin Skills**.

Following this, you should decide your stats. There are 11 abilities (**Spellcraft**, Diligence, Deftness, Prowess, Power, Fortitude, Will, Discern, Convey, Agility, and Recall). Each one may have one dice from the following array: 3d4, 2d6, 2d8, 2d10, 2d12.

You then get 20 [[Skill Points]] (not to be confused for skill pills) to use as you see fit. Each node has a listed cost. When you select that node, subtract the cost from your total and keep going until you have the skills you want, or run out of points. The GM can choose to change the number of [[Skill Points]] if they so desire.

The main skill trees are:

- [Adaptation](Adaptation.canvas)
- [Combat](Combat.canvas)
- [Crafting](Crafting.canvas)
- [Exploration](Exploration.canvas)

- [Spellcraft](Spellcraft.canvas)
